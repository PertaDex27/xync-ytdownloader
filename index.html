Penggunaan API

Mau nempel downloader ini ke web/apk lu? Tenang, ada API-nya kok. Tinggal GET aja, ntar dapet JSON:

1. Ambil info video (judul, thumbnail, dll)
GET /api/info?url=<link youtube>
{ "status": "ok", "videoId": "dQw4w9WgXcQ", "title": "...", "author": "...", "thumbnail": "..." }
2. Ambil link downloadnya
GET /api/download?url=<link youtube>&format=mp3&quality=320
{ "status": "ok", "url": "https://...", "format": "mp3", "quality": "320" }

Tambahin &stream=1 kalau mau dapet progress realtime (Server-Sent Events). Format yg ada: mp3 (320–64 kbps), mp4 (2160p–144p), m4a & opus (320 kbps). Gak perlu login, gak perlu apikey.
